# Ahmad Mahmoud

ML engineer working on **Arabic NLP** and **LLM agent tooling**. I train small models that run on CPU, and I build the tools agents need to work well on long projects.

- 🔤 I publish open Arabic diacritization (tashkeel) models on [Hugging Face](https://huggingface.co/ahmadsy)
- 🤖 I wrote a TypeScript port of Hugging Face smolagents
- 🛠️ Python · TypeScript · PyTorch · ONNX · React · Kotlin
